2.  Select the **Syncs** tab.
3.  Select the **Variables** you want to sync.
4.  Click the **Syncs** button.
5.  Wait for the sync to finish.

## How to Syncs The Variables To Github

Your variables will be synced to github automatically when you click the **Syncs** button. And github action will trigger the build script to build the variables and commit it back to the repo. As long as the developers use the correct variable name and pull the latest changes, they will get the latest variables and style tokens are automatically updated.
