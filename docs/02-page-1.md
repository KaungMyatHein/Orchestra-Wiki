# ⚙️ Plugin Setting


## The Power of Columns
The automation script uses **Position-Based Mapping**. This means the script aligns tokens based on their column index, regardless of their name.

## Figma Variables Structure

The figma variables should be structured in the following way:
* Primitive Variable Token
* Semantic Variable Token (For Large Projects)
* Component Variable Token

Look at this video tutorial for how to set up the setting for plugin.

1.  Open the **Orchestra Syncs** plugin in Figma.
2.  Add your Github Personal Access Token in the plugin settings.
3.  Add your Repository and Branch.
4.  Save your settings and setting will be saved in the **Figma Client Storage** which means it will be saved in your local machine. If you set in the **Figma Desktop App**, it will be saved in your desktop app. If you set in the **Figma Web App**, it will be saved in your web app. So, it is recommended to use the **Figma Desktop App** for the production level projects.
