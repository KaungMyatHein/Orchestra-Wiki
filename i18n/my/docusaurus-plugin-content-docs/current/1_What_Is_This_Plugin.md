# Orchestra Sync ဆိုတာ ဘာလဲ?

Design နဲ့ Development ကြားက အတားအဆီးတွေ ပျက်ပြားသွားမယ့် ကမ္ဘာတစ်ခုကို မြင်ယောင်ကြည့်လိုက်ပါ။ အဲဒါကတော့ **Orchestra Sync** က ဖန်တီးပေးမယ့် ကမ္ဘာပါပဲ။

**Orchestra Sync** ဆိုတာ သင့် Design System သံစုံတီးဝိုင်းကြီးရဲ့ "Conductor" (တီးဝိုင်းမှူး) တစ်ယောက်ပါပဲ။ သူက သင့်ရဲ့ ဖန်တီးမှုရလဒ်တွေနဲ့ တိကျခိုင်မာတဲ့ Code ကမ္ဘာကြီးကြားကို ဆက်သွယ်ပေးမယ့် အထူးပြုလုပ်ထားတဲ့ Figma Plugin တစ်ခုဖြစ်ပါတယ်။

## ပြဿနာ
ရိုးရာနည်းလမ်းတွေမှာ Designer က Figma ထဲမှာ "Primary Blue" အရောင်တစ်ခုကို ဖန်တီးလိုက်တယ်။ ပြီးရင် Developer ကို လွှဲပေးလိုက်တယ်။ Developer က `#18A0FB` ဆိုတဲ့ Code ကို သူ့လက်နဲ့ ကိုယ်တိုင် ရိုက်ထည့်ရတယ်။
ရက်သတ္တပတ်တွေကြာတော့ Design က `#0D8ADB` ကို ပြောင်းသွားတယ်။ Developer က မသိလိုက်ဘူး။ ဒီလိုနဲ့ Product ကြီးမှာ ရှေ့နောက်မညီတာတွေ ဖြစ်လာရော။

## ဖြေရှင်းနည်း
**Orchestra Sync** က ဒီလို လက်ဆင့်ကမ်းရတဲ့ လုပ်ငန်းစဉ်ကို အလိုအလျောက် လုပ်ဆောင်ပေးပါတယ်။ သူက သင့်ရဲ့ Figma Variables တွေ (Colors, Spacing, Typography စတာတွေ) ကို **Design Tokens** (JSON code) အဖြစ် ချက်ချင်း ပြောင်းလဲပေးပြီး Engineering Team ရဲ့ GitHub Repository ဆီကို တိုက်ရိုက် ပို့ပေးပါတယ်။

သူက ဖိုင်တစ်ခုကို "Export" ထုတ်ပေးလိုက်ရုံ သက်သက် မဟုတ်ပါဘူး။ "Live Link" တစ်ခုလို ချိတ်ဆက်ပေးထားတာပါ။ Figma မှာ အရောင်တစ်ခု ပြောင်းလိုက်တာနဲ့၊ Orchestra Sync က Code ဘက်မှာပါ ပြောင်းလဲသွားအောင် လုပ်ဆောင်ပေးပါတယ်။ Design ဖိုင်ထဲက " အမှန်တရား (Source of Truth)" ဟာ လက်တွေ့ App ထဲက "အမှန်တရား" နဲ့ တစ်ထပ်တည်း ဖြစ်နေစေမှာပါ။

ဒါဟာ Tool တစ်ခု သက်သက် မဟုတ်ပါဘူး၊ သင့် Product ရဲ့ Design Language တစ်ခုလုံးအတွက် တစ်ခုတည်းသော "Source of Truth Engine" ဖြစ်ပါတယ်။
