# ထိန်းချုပ်ခန်း

## ၎င်းက ဘာလဲ။
`package.json` ဖိုင်သည် Node.js ပရောဂျက်တိုင်း၏ နှလုံးသည်းပွတ် ဖြစ်သည်။ ၎င်းတွင် ကျွန်ုပ်တို့လိုအပ်သော Tool များနှင့် Run ရမည့် Command များ ပါဝင်သည်။ Orchestra Sync အလုပ်လုပ်နိုင်ရန်၊ ဒီဖိုင်ထဲမှာ စာကြောင်းအနည်းငယ် ထည့်သွင်းပေးဖို့ လိုအပ်ပါသည်။

## ၁။ Scripts
"ဟေ့ကောင်... `build.js` ဆိုတဲ့ ဘာသာပြန်စက်ကြီးကို မောင်းနှင်ပေးစမ်းပါ" လို့ ကွန်ပျူတာကို ခိုင်းစေဖို့ Command တစ်ခု လိုအပ်ပါတယ်။

သင့် `package.json` ရဲ့ `"scripts"` အပိုင်းမှာ ဒါလေး ထည့်ပေးပါ-

```json
"scripts": {
  "tokens": "node build.js"
}
```

ဒါဆိုရင် GitHub Action က `npm run tokens` လို့ အမိန့်ပေးလိုက်တာနဲ့ ဘာလုပ်ရမလဲဆိုတာ အတိအကျ သိသွားပါလိမ့်မယ်။

## ၂။ Dependencies (မှီခိုအားပြုရမည့်အရာများ)
ကျွန်ုပ်တို့၏ `build.js` သည် ပေါ့ပါးပြီး (`fs`, `path` ကဲ့သို့) အသင့်ပါပြီးသား Tool များကိုသာ အသုံးပြုထားသည်။ သို့သော် သင်သည် script ကို `style-dictionary` ကဲ့သို့သော အခြား Library များသုံးပြီး ချဲ့ထွင်ထားလျှင်တော့ ၎င်းတို့ကို ဒီနေရာမှာ စာရင်းသွင်းရပါလိမ့်မယ်။

ပုံမှန် `build.js` အတိုင်းပဲ သုံးမယ်ဆိုရင်တော့၊ ဘာမှ ထပ်ထည့်စရာ **မလိုပါ**။

## ဥပမာ ဖိုင်
အနည်းဆုံး လိုအပ်ချက်များပါဝင်သော `package.json` ပုံစံမှာ ဒီလို ရှိပါလိမ့်မယ်-

```json
{
  "name": "my-design-system",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "tokens": "node build.js"
  },
  "devDependencies": {
    "typescript": "^5.0.0"
  }
}
```

:::tip "type": "module" အကြောင်း သိမှတ်ဖွယ်
အကယ်၍ သင့် `build.js` က `import` / `export` (ခေတ်မီ Javascript) ကုဒ်များကို သုံးထားလျှင်၊ `package.json` ထဲတွင် `"type": "module"` ဟု ထည့်ပေးရန် လိုအပ်ပါသည်။ သို့မဟုတ်ပါက သင့် script ဖိုင်အမည်ကို `build.mjs` ဟု ပေးရပါမည်။
:::
