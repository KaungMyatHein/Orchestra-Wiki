# Settings များကို ဘယ်လို ပြင်ဆင်မလဲ?

Orchestra Sync ကို စတင်အသုံးပြုဖို့အတွက် သင့် Design File နဲ့ Code Repository ကို ချိတ်ဆက်ပေးဖို့ Setting ချိန်ညှိမှု တစ်ကြိမ် ပြုလုပ်ရပါမယ်။ ဒါဟာ ဖျော်ဖြေပွဲမစခင် ဂီတတူရိယာတွေကို အသံညှိတာနဲ့ တူပါတယ်။

## အဆင့် ၁ - Authentication (သော့)
ပထမဆုံး တံခါးကို ဖွင့်ဖို့ရာ သော့တစ်ချောင်း လိုပါတယ်။ မင်းမှာ **GitHub Personal Access Token (PAT)** ရှိဖို့ လိုပါတယ်။
1.  Plugin ထဲက **Settings** tab ကို ဖွင့်ပါ။
2.  "Personal Access Token" ဆိုတဲ့ အကွက်ကို တွေ့ပါလိမ့်မယ်။
3.  ဒီ Token ဟာ "ကျွန်တော် ဒီမှာ ပြုပြင်ပြောင်းလဲမှုတွေ လုပ်ခွင့်ရှိတယ်" လို့ GitHub ကို ပြောပြမယ့် သင့်ရဲ့ Digital ID ကတ်ပြားပါပဲ။
4.  ထည့်သွင်းပြီးသွားရင် Status က **🟢 Connected** ဆိုပြီး ပြောင်းသွားပါလိမ့်မယ်။

## အဆင့် ၂ - ပန်းတိုင် (The Destination)
အခု... သီချင်းသံစဉ်တွေ ဘယ်ကို သွားရမလဲဆိုတာ Plugin ကို ပြောပြပါ။
*   **Repo Owner:** Code တွေကို ပိုင်ဆိုင်တဲ့ အဖွဲ့အစည်း သို့မဟုတ် Username (ဥပမာ - `facebook` သို့မဟုတ် `your-company`).
*   **Repo Name:** Project ဖိုင်တွဲ နာမည် (ဥပမာ - `react` သို့မဟုတ် `design-system`).
*   **Branch:** သင့်ရဲ့ အပြောင်းအလဲတွေ ရောက်ရှိသွားမယ့် Timeline လမ်းကြောင်း။ ရိုးရှင်းတဲ့ Project တွေအတွက် `main` ဖြစ်လေ့ရှိပြီး၊ ပိုစိတ်ချရတဲ့ Workflow တွေအတွက်တော့ `design-tokens` ဆိုတဲ့ Branch သီးသန့် ထားလေ့ရှိပါတယ်။

## အဆင့် ၃ - ဖိုင်လမ်းကြောင်း (The File Path)
ဖိုင်ကို ဘယ်နေရာမှာ သိမ်းမှာလဲ? "File Path" ကို သတ်မှတ်ပေးရပါမယ်။
*   ဥပမာ - `tokens/design-tokens.json`
*   ဒါက Plugin ကို " `tokens` ဆိုတဲ့ ဖိုင်တွဲထဲသွား၊ ပြီးရင် `design-tokens.json` ဆိုတဲ့ နာမည်နဲ့ အကုန်လုံး စာရင်းမှတ်လိုက်" လို့ ပြောတာနဲ့ တူပါတယ်။

## အဆင့် ၄ - တူရိယာများ စုဖွဲ့ခြင်း (Sync Groups)
နောက်ဆုံးအနေနဲ့၊ **Sync Tokens** tab မှာ *ဘာတွေ* ပို့မလဲ ဆိုတာ သတ်မှတ်ပါ။
1.  **+ Add Group** ကို နှိပ်ပါ။
2.  Type ကို ရွေးချယ်ပါ - **Color**, **Spacing**, သို့မဟုတ် **Typography**.
3.  ဒီ Group နဲ့ သက်ဆိုင်တဲ့ Figma Variable Collections တွေကို ရွေးချယ်ပါ။ ဥပမာ - သင်က "Primitives" နဲ့ "Tokens" collections တွေကို "Color" group ထဲမှာ ထည့်သွင်း ချိတ်ဆက်နိုင်ပါတယ်။

ဒီအဆင့်တွေ ပြီးသွားပြီဆိုရင်တော့၊ သင့်ရဲ့ Orchestra တီးဝိုင်းကြီးဟာ နေရာယူပြီးပြီမို့ တီးခတ်ဖို့ အဆင်သင့် ဖြစ်နေပါပြီ။
