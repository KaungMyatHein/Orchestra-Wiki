# ကြိုတင်လိုအပ်ချက်များ

Orchestra Sync နဲ့ သင့် Design System ကို မစီမံခန့်ခွဲခင်မှာ၊ ဇာတ်ခုံ နေရာချထားမှု အဆင်သင့် ဖြစ်မဖြစ် စစ်ဆေးရပါမယ်။ မရှိမဖြစ် လိုအပ်ချက် အချို့ ရှိပါတယ်။

## ၁။ GitHub Account နှင့် Repository
လိပ်စာမရှိဘဲ စာပို့လို့ မရပါဘူး။
*   သင့်မှာ အသုံးပြုနေတဲ့ **GitHub account** တစ်ခု ရှိရပါမယ်။
*   သင် Code ရေးသားခွင့် (Write access) ရှိတဲ့ **Repository** (Project Folder) တစ်ခု ရှိရပါမယ်။

## ၂။ ရွှေရောင်သော့ - Personal Access Token (PAT)
Plugin ဝင်ရောက်နိုင်ဖို့ GitHub က ပေးတဲ့ သော့တစ်ခု လိုအပ်ပါတယ်။
*   **Classic Token:** `repo` scope ကို အမှန်ခြစ် ပေးလိုက်ရင် ရပါပြီ။ ဒါဆို Private repositories တွေကိုပါ အပြည့်အဝ ဝင်ရောက်ခွင့် ရရှိမှာပါ။
*   **Fine-Grained Token:** လုံခြုံရေးကို ပိုဂရုစိုက်ချင်ရင်တော့၊ သင့် Repository အတွက် သီးသန့် Token ထုတ်ပြီး **Contents** နဲ့ **Pull Requests** တွေပေါ်မှာ **Read and Write** access ပေးလိုက်ပါ။
:::info
At least you need to have PAT generated by your tech team to syncs to their repo.
သင့်ဆီမှာ Github Account မရှိရင်တောင် Tech Team ဖက်ကနေ သင့်အတွက် ထုတ်ထားပေးမယ့် PAT လေးတော့ ရှိရပါမယ်။
:::

## ၃။ Figma Variables
Orchestra Sync က Styles တွေကို နားမလည်ပါဘူး၊ **Variables** ဘာသာစကားကိုပဲ ပြောတတ်ပါတယ်။
*   သင့် Figma File ဟာ Colors, Numbers (Spacing), သို့မဟုတ် Strings တွေအတွက် ခေတ်မီ **Variables** Feature ကို အသုံးပြုထားရပါမယ်။
*   ရှေးရိုးစွဲ "Styles" (Paint Styles, Grid Styles) တွေဟာ ဒီစနစ်ရဲ့ ဘိုးဘေးတွေ ဖြစ်ပြီး Orchestra Sync က **မထောက်ပံ့ပါ (Not Supported)**။ Variables စနစ်ကို အရင် ပြောင်းလဲ (Migrate) ခဲ့ဖို့ လိုပါလိမ့်မယ်။
![Figma Variables](/img/figma-variables.png)

## ၄။ အင်တာနက် လိုင်း
ပြောဖို့တောင် မလိုလောက်အောင်ပါပဲ။ ဒါပေမယ့် Plugin က တံတားတစ်စင်း ဖြစ်တဲ့အတွက်၊ Figma Server တွေရော၊ GitHub API နဲ့ပါ ချိတ်ဆက် စကားပြောဖို့ ကောင်းမွန်တဲ့ အင်တာနက် လိုင်းတစ်ခု လိုအပ်ပါတယ်။
